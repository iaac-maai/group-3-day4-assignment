# Data attribution

Original dataset: Property Rental Listings Dataset, Harshal Honde (Kaggle user
harshalhonde), https://www.kaggle.com/datasets/harshalhonde/property-rental-listings-dataset.

The group's existing Day 2/Day 3 documentation declares CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/ . This declaration is inherited
from the source records; it has not been independently rechecked online in
this local-only preparation session.

Group 3 cleaned the Mumbai listings into 18,846 rows and 26 columns. This
project copies that cleaned snapshot unchanged, retaining its row order.
SHA-256: 354d28e07432137cdc97a2197a556269137e74135af01186420e2e2917a19ee9.

Historical Day 2 source: https://github.com/iaac-maai/group-3-day2-assignment
at snapshot 6b2a6d17af8c4d8950f12e60dc97f8b9a8d4dbc1, as documented in
the group's local Day 3 dataset card. No new network retrieval was used here.

Raw descriptions and titles are not model inputs. Area units, listing date,
duplicate dwellings, listing authenticity and geographic representativeness
remain unverified. This is an educational dataset, not current market evidence.
